BTT United — วิธีติดตั้งบน XAMPP
1) เปิด XAMPP Control Panel -> Start Apache
2) วางโฟลเดอร์ btt-united ที่ C:\xampp\htdocs\
3) เปิด http://localhost/btt-united/
4) ต้องต่ออินเทอร์เน็ตไว้ (Bootstrap/ไอคอน/ฟอนต์/แผนที่ โหลดจาก CDN)
แก้ข้อมูลบริษัท (โทร อีเมล ที่อยู่ Facebook LINE วิดีโอ ใบรับรอง) ที่ไฟล์ config.php ที่เดียว
ข้อความจากฟอร์มติดต่อดูได้ที่ data/messages.csv
เปลี่ยนรูป: วาง hero-1.jpg ... gallery-3.jpg ใน assets/img/ (ดู README.txt ในโฟลเดอร์นั้น)
